# Block Fall - Debug APK Download

The debug APK has been built and placed in visible root folders so you can easily view, download, and install it on your Android phone:

- **Folder:** `/build-outputs/app-debug.apk`
- **Folder:** `/downloads/app-debug.apk`

### How to install on your phone:
1. Tap on `build-outputs` or `downloads` in the AI Studio file explorer on the left.
2. Select `app-debug.apk`.
3. Download/open the file to install it directly on your Android device.
